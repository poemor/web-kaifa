# 开发练习册 · 设计评审预览

状态：历史设计预览，方案已获用户确认并实施到根目录学习网站。日期：2026-10-13。此目录保留为评审参考，日常学习请使用根目录 `index.html`。

这是独立的前端设计方案，呈现首页、课内工作台和知识查找三个视图。沿用根目录 `tokens.css` 中已采用的暖纸色、炭灰、陶土色与中文字体栈，读取现有课程和知识数据。

## 打开

在仓库根目录执行：

```powershell
python -m http.server 8743
```

访问 `http://127.0.0.1:8743/projects/web/workbook-design-review/`。也可以直接打开此目录的 `index.html`；文件协议下自动复制可能受浏览器限制，可手动选择文字。

## 建议评审顺序

1. 首页切换 Web / Go 与学习起点，查看当前课与路线的层级。
2. 进入课程，体验“读懂任务 → 动手写 → 验收记录”。目录可切换现有 42 课。
3. 打开“整理提问”。桌面大屏在正文右侧显示；小屏在当前内容后、页脚前显示，并定位到标题。收起后返回触发位置。
4. 修改代码，手动运行；切换课时再返回，查看当前页面内保留的代码草稿。
5. 在“查找知识”输入关键词，切换方向，尝试无结果再清空筛选。

## 验证

需要 Node.js、Playwright 与本机 Edge。已有 Playwright 环境中，在根目录执行：

```powershell
node projects/web/workbook-design-review/verify.cjs
node scripts/check_site.cjs
node scripts/test_site.cjs
node scripts/test_workbench.cjs
```

如 Playwright 在外部运行时目录，先把其 `node_modules` 路径设置到 `NODE_PATH`。不需要为预览安装新依赖或建立构建流程。

预览检查覆盖 3 个视图 × 320 / 375 / 414 / 768 / 1024 / 1440px，检查横向溢出、操作按钮、键盘标签、帮助定位与返回、空提问错误、旧提问结果失效、隔离手动预览、逐课草稿、搜索空状态与 localStorage 不变。截图和结果保存在根目录 `.qa/`，不提交。

## 已知限制

- 这是布局与交互原型，不是正式学习网站的替代版；左栏三个入口用于评审视图，正式版仍保留全部内容入口。
- 不读写学习记录、笔记备份或完成状态；代码和提问草稿只在当前页面内暂存。刷新后丢失，验收勾选与笔记切换视图后也不保留。
- 不连接模型，不发送问题；只生成可复制文字。不演示扩展连接成功或虚构回答。正式实施必须兼容已有官网桥接扩展。
- 工作台展示真实课程标题、任务、概念和提示；完整讲义与小测仍通过链接进入现有站点。
- HTML 可以在隔离 iframe 中手动运行。CSS / JavaScript 使用简化容器，不能代替实际课程的配套 DOM；需要服务或项目环境的片段按讲义在本机运行。
- Go 不在浏览器执行；源码仍来自真实课程。该原型尚未接入零基础 Go 第 2 课适配，正式实施必须保留现有适配逻辑。
- 剪贴板自动复制依赖浏览器权限；失败后支持选择生成文本手动复制。

审核依据、具体问题、正式实施文件和验收计划见 [前端设计审核](../../../docs/frontend-design-review-2026-10-13.md)。
