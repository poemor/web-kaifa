# 阅读展示优化与验证

2026-10-13。完整读取入口、样式、课程渲染、起步页、知识讲义、工作台和状态交互后，按统一左栏方案优化。暖纸色、炭灰、陶土强调和原有设计变量继续共用。

## 展示改动

起步教程的主题与段落目录、系统章节的小目录、知识与阶段项目的目录统一放到最左栏。正文里不再重复放一列目录；手机展开“目录”后选择段落，先收起导航，再滚动并把键盘焦点交给标题。

标题区压缩，桌面正文从左栏旁开始。段落控制行宽，代码和表格使用更宽空间。代码保留原始换行，超长行在代码框内横滚；长表格在自身容器内滚动，有操作提示、可见焦点和方向键支持。准备顺序、前置知识和启动说明可展开，原正文、链接、图片与源码下载保持完整。

系统教程的阶段与分页继续只更新左栏，不重建正在阅读的正文，不丢失滚动、已展开答案或提问草稿。原课程记录完成、恢复源码及撤销导致正文重建时，也会重新挂载阅读增强。笔记、用户代码、验收、小测、完成记录、备份撤销、代码隔离和助教协议保持原规则。

## 实际检查

- 独立基线审查覆盖12种路由与8种宽度，共96个场景，指出重复目录、正文窄、手机正文过低、长表格、截断标题、触控与导航问题。
- 新阅读检查覆盖10种路由与8种宽度，共80个场景；9种正文与原渲染函数生成的文字、代码、表格、链接、图片逐项一致。
- 真实键盘检查包含24次长表格和21次长代码横滚，页面本身没有横向溢出。手机跳段的焦点、高亮、目录收起均检查；1920px手动滚动高亮与页底点击竞态有回归覆盖。
- 系统目录95个分页场景通过；检查125章可达、全部阶段、地址恢复、正文DOM、滚动、答案、提问与旧学习记录。原起步、知识、课内状态、工作台、Go起步230项和12阶段项目浏览器检查也再次通过。
- 本机发布核验检查22份脚本/样式、125篇Markdown、17个ZIP与5张截图的实际内容，以及234个页面入口和19页章节目录。线上发布需在Pages构建完成后另行运行同一核验，不能用本机结果代替。
- 修改完成后由未参与实现的agent再次独立读取与浏览器复验：6类页面×8宽度共48个组合通过，基线5项主要问题与3项细节问题全部关闭；另实测手机键盘焦点、1920px高亮、目录独立滚动、课内正文重建和助教1199/1200px布局边界，无发布阻碍。

Go起步页在375px宽度下，第一处正文小标题从页面顶部约1491px移到569px；1440px下正文可用宽度从647px增加至1096px。测量使用同一页面与1000px高视口，浏览器字体差异可能改变少量位置。

测试通过说明本轮界面与交互符合这些检查；浏览器验证基于本机Edge与手机视口模拟，未使用实体手机或真实AI账号。教程内容由另三名新agent逐章审核，见[系统教程审核](course-audit.md)。阅读不表示学习者完成课程；静态网站也不会运行Go服务器、数据库或容器项目。
