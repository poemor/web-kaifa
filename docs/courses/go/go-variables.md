# 变量声明与赋值

用 var 和 := 保存一个值，再用 = 修改已有变量。

## 变量声明与赋值是什么意思

变量给程序中的值起一个名字。声明创建这个名字，赋值把一个值存到这个名字对应的位置。`var score int = 80` 明确声明整数；函数内的 `score := 80` 让 Go 根据初值确定类型。已经声明过的变量用 `=` 修改。

## 声明、赋值、读取是三个动作

**变量是一个有名字、能保存某类值的位置；打印变量会读它当前的值。** “声明”创建名字，“赋值”存入或更新值，“读取”取得已经保存的值。

| 写法 | 发生的动作 |
| --- | --- |
| `var score int = 80` | 声明一个整数变量，初值为 80 |
| `var score = 80` | 声明变量，由初值推断为整数 |
| `score := 80` | 在函数内简写声明，并提供初值 |
| `score = 90` | 给已经存在的 score 重新赋值 |
| `fmt.Println(score)` | 读取当前分数并输出 |

上面前三行是声明的不同写法，练习时**选其中一种**，不要放在同一个范围内重复声明三遍。同一个变量可以多次赋值。类型会在下一课详细解释。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	// := 第一次声明 score，并把整数 80 作为初值。
	score := 80
	fmt.Println(score) // 不加引号：读取变量当前保存的值。
	// = 更新已有变量；这一步没有创建第二个 score。
	score = 90
	fmt.Println(score) // 前面的赋值已执行，因此这里读到 90。
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
80
90
```

## 逐步读懂这个例子

第一行创建 score 并放入 80。第一次打印读取当前值 80。`score = 90` 把值更新为 90，第二次打印读到的是更新后的值。变量名没有引号；`"score"` 打印的是这个单词本身。

可以把执行前后写成小表：

| 已执行到哪一步 | score 当前值 | 终端新增内容 |
| --- | --- | --- |
| 声明并赋初值 | 80 | 没有 |
| 第一次打印 | 80 | 80 |
| 更新赋值 | 90 | 没有 |
| 第二次打印 | 90 | 90 |

**赋值不会自动输出，打印不会自动修改分数。** 同样，更新变量不会把终端已经打印的 80 改成 90。

## 本节容易混淆的地方

同一作用域重复写 score := 90 会报“no new variables”。局部变量声明后要使用；变量名不能以数字开头。

## 试一次声明错误，再恢复

把第二次赋值 `score = 90` 改成 `score := 90`。同一个范围没有新变量可声明，运行应报错，且不会产生本课的正常输出。恢复 `=` 后重新运行。

再把第一次输出改为 `fmt.Println("score")`：它应输出文字 `score`；改回 `fmt.Println(score)` 才会读取 80。解释这两次差别，比背住符号更重要。
