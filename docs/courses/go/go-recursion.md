# 递归与停止条件

跟踪函数调用自己，确认输入逐步靠近停止条件。

## 先认识一个可以拆小的问题

阶乘表示从正整数 n 一直乘到 1。例如 3 的阶乘写成 3!，结果是 3×2×1=6；0! 按定义为 1。于是 5! 可以拆成 5×4!，4! 再拆成 4×3!，直到小问题可以直接给出答案。

递归就是一个函数在自己的计算过程中再次调用自己。**递归必须有停止条件，也必须让每次调用的输入更接近停止条件。** 每次调用有自己的参数 n；这不是反复修改同一个全局 n。

先会 [函数调用和返回](../../../index.html#/learn/go/go-functions)、[if 条件](../../../index.html#/learn/go/go-if)。本节只用 0 到 10 的小整数，暂不解决负数或大数计算。

## 完整 main.go

在已初始化的独立目录，替换 main.go，保存后运行：

```go
package main

import "fmt"

// Factorial 只在本课的小非负整数范围内计算阶乘。
func Factorial(n int) int {
	if n <= 1 {
		return 1 // 停止条件：0! 与 1! 都是 1，不再调用自己。
	}
	// 先取得较小问题的结果，再乘当前 n；每次 n 都减少 1。
	return n * Factorial(n-1)
}

func main() {
	fmt.Println(Factorial(5)) // 计算 5×4×3×2×1。
}
```

```sh
go run .
```

预期终端输出：

```output
120
```

## 先往下调用，再往上返回

Factorial(5) 还不能直接知道 4!，所以暂时等 Factorial(4) 的结果。接着按 5→4→3→2→1 调用，到 n=1 时直接 return 1，不再调用。

| 返回阶段 | 当前计算 | 返回给上一层 |
| --- | --- | --- |
| Factorial(1) | 直接返回 | 1 |
| Factorial(2) | 2×1 | 2 |
| Factorial(3) | 3×2 | 6 |
| Factorial(4) | 4×6 | 24 |
| Factorial(5) | 5×24 | 120 |

最终 main 得到 120 才打印。源码里的 return 可以包含另一次调用：先求出 `Factorial(n-1)`，再乘 n，最后返回当前结果。

## 预测停止与非法输入

| 输入 | 本节有效输入吗 | 预期 |
| --- | --- | --- |
| 0 | 是 | 1 |
| 1 | 是 | 1 |
| 3 | 是 | 6 |
| -1 | 否 | 现有函数会返回 1，这不是合法的负数阶乘 |

按前三个输入分别运行，记录结果。负数案例说明本函数依赖输入前提，不能把 `n<=1` 理解为已经校验所有整数。

若把 n-1 错写成 n，n=5 永远不会接近停止条件；若去掉停止分支，也会继续调用直到程序无法继续。先在纸上指出错误，不必故意让程序耗尽调用空间。int 的范围有限，大阶乘还可能溢出，当前程序不是任意精度工具。

## 独立写一个更小的递归

写 Sum(n int) int，计算 1 到 n 的和：n=0 时返回 0，其他有效输入返回 n 加上 Sum(n-1)。先手算 Sum(3)=6、Sum(0)=0，再运行；输入同样只允许本课的小非负整数。

### 参考答案

停止分支负责给出最小问题的答案；n-1 保证逐次变小；调用返回后才组合结果。不能只说“它会自己重复”，需要能按表格追踪每层的输入和返回值。
