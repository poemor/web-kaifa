# switch 多分支选择

按一个值选择明确的分支，处理没有匹配的情况。

## switch 多分支选择是什么意思

switch 适合从多个离散值中选择一种情况。case 给出匹配值，default 处理未匹配的值。Go 的普通 case 执行后结束，不需要像某些语言一样在每个分支加 break。

## 一组离散值用 case 列清楚

`if` 常判断数值范围，`switch day` 可以按一个具体值选择规则。每个 case 后面写一个或多个可匹配的值，冒号后是匹配时的语句。**普通 case 执行后就结束这个 switch，不会自动接着执行下一个 case。**

`default` 的意思只是“没有任何 case 匹配”，不等于“输入已经合法”。本例有意用最少的分支演示选择；它把所有非周末文字都归入工作日，不能当作严谨的日期校验。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	day := "周六"
	// 取 day 的值，按顺序与各个 case 列出的值比较。
	switch day {
	case "周六", "周日": // 逗号表示两种值都进入这个分支。
		fmt.Println("休息日")
	default: // 前面没有任何匹配时才执行。
		fmt.Println("工作日")
	}
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
休息日
```

## 逐步读懂这个例子

day 的值匹配第一个 case 中的周六，所以打印休息日。这个 case 列了两个可选值，用逗号分隔。换成周一会进入 default。

把执行写成三个问题：day 是什么？它有没有等于“周六”或“周日”？若都没有，default 要做什么？这三个问题足够解释当前例子，不用猜测 Go 能否理解自然语言星期。

如果不写 default，未匹配时什么也不输出，程序继续执行 switch 后的语句。switch 结束不代表整个 main 必须结束。

## 自己改一处再运行

将 day 依次改成周日、周一、未知，观察 default 的含义。

### 参考答案

周日是休息日；周一和未知都输出工作日。若要拒绝未知值，需要专门的校验，而不是让 default 猜测。

## 本节容易混淆的地方

switch 的分支是你定义的规则，default 不能自动判断业务输入是否合法。

## 让规则处理未知值

保持“周六、周日”分支，新增“周一”到“周五”的 case，最后把 default 改为输出“未知星期”。依次试周日、周一、未知，预期是休息日、工作日、未知星期。

若 case 少写引号，会把名字当成变量而产生编译错误。恢复字符串写法，再核对三条输入，不能只测试周六一种。

参考：[Go 语言规范](https://go.dev/ref/spec)。
