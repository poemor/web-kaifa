# if 与 else 条件语句

根据分数选择执行哪一个分支。

## if 与 else 条件语句是什么意思

if 后面的布尔条件为 true 时，执行紧接着的花括号内容；为 false 时可以进入 else。一个 if/else 中两边不会同时执行。先学两个分支，再用 else if 表达多个范围。

## 先判断，再选一段代码执行

顺序执行是从上往下走；条件分支是在某个位置选择一条路。**if 后面必须得到 true 或 false；同一次 if/else 只执行匹配的一边。** 本课判断“是否至少 60 分”，它与“分数是否在合法范围内”是两个不同的问题。

当要分成更多范围时可以接 `else if`。例如先判断 `score < 0 || score > 100` 是否非法，再判断 `score >= 60` 是否及格，最后处理未及格。程序按顺序检查，匹配后不会继续执行后面的分支。这里的 `||` 已在运算符课解释。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	score := 60
	// 先计算比较结果；只有为 true 时才进入这对花括号。
	if score >= 60 {
		fmt.Println("及格")
	} else {
		// 同一次判断不满足条件时，执行另一边。
		fmt.Println("未及格")
	}
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
及格
```

## 逐步读懂这个例子

score 是 60，60>=60 为 true，所以只打印及格。分支里的语句在条件成立时才会执行。Go 的条件不必额外套一层圆括号，但分支花括号必须保留；else 通常与前一个 } 写在同一行。

| score | `score >= 60` | 进入哪里 | 输出 |
| --- | --- | --- | --- |
| 59 | false | else 的花括号 | 未及格 |
| 60 | true | if 的花括号 | 及格 |
| 100 | true | if 的花括号 | 及格 |

花括号内部的缩进表示这一分支包含哪些语句；**决定范围的是配对花括号，不能只靠缩进猜测。** 分支结束后，函数仍会继续执行 if/else 后面的语句。

## 自己改一处再运行

用 59、60、100 分别运行，并记录三个结果。

### 参考答案

59 未及格，60 与 100 及格。这三次分别检查了下边界、临界点和正常较高分。

## 本节容易混淆的地方

不要把 = 当作 ==。输入 120 也会进入及格分支；想限制 0..100，需要另外写输入有效性检查。

## 检查未覆盖的输入

先运行 -1 和 120。原程序会分别显示未及格与及格，说明它没有检验 0–100 的范围。再亲手在最前面加非法范围分支，让两种值都输出“分数无效”，并确认 59、60、100 仍正确。

把条件写成 `if score {` 会报错，因为 score 是整数，不是布尔值。恢复明确的比较条件后再运行。
