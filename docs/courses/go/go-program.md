# Go 程序结构

看懂 package、import、main 和一条打印语句，运行后得到一行文字。

## Go 程序结构是什么意思

一个可运行的 Go 文件通常先声明包，再引入用到的包，最后定义程序入口。先看这个只有一条输出语句的程序：从 main 的左花括号进入，执行打印，再从右花括号结束。包和模块的完整组织方式会在后面单独学习。

## 先分清“源码、编译、运行、输出”

源码是你写给 Go 工具看的文字，保存在 `.go` 文件里。编译会先检查语法和名字，把正确的源码变成机器能够执行的程序。运行才会真正执行里面的语句。终端里的输出是程序产生的结果。

**写好代码并保存，才算改好了要运行的文件；网页里的代码示例不会替你在电脑上执行。** 本课只需要上一节准备好的独立文件夹、`go.mod` 和终端。

`main.go` 的文件名与 `func main()` 的函数名是两回事。前者方便我们找到源码，后者是 Go 规定的可执行程序入口。现在照着保留 `package main` 和 `func main()`，后续学函数和包时再展开它们的组织方式。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
// main 包告诉 Go：这里是一个可执行程序。
package main

// fmt 是 Go 自带的输出工具；引入后才能使用 fmt.Println。
import "fmt"

// 程序启动后进入 main，依次执行花括号里的语句。
func main() {
	// 括号内的字符串是输出内容，Println 会在末尾换行。
	fmt.Println("你好，Go")
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
你好，Go
```

## 逐步读懂这个例子

1. `package main` 表明这个文件属于可执行程序使用的 main 包。
2. `import "fmt"` 引入 Go 自带的 fmt 包；本例用它在终端输出文字。
3. `func main()` 定义入口函数。`func` 表示定义函数；括号后的花括号包住入口内的语句。
4. `fmt.Println("你好，Go")` 调用打印函数。点号连接包名和函数名，括号里是要打印的内容，双引号表示字符串。
5. Println 打印后换行。程序结束，终端再次出现提示符。

执行时可以用手指按这个顺序跟读：进入 `main` → 调用 `fmt.Println` → 显示文字并换行 → 离开 `main`。`import` 让打印工具可用，但它本身不打印内容。

括号内的内容叫这次调用的**参数**，也就是交给函数处理的数据。这一课只传一段文字；参数为什么可以是数字、函数怎样返回结果，后面的课程会分别讲。

## 自己改一处再运行

只把引号里的文字改成“我开始学习 Go”，预测输出，保存后重新运行。

### 参考答案

输出应为“我开始学习 Go”。如果仍显示旧句子，先检查保存的文件与终端目录。

## 本节容易混淆的地方

`main.go` 是源码文件，`go run .` 是终端命令。Println 的 P 大写，中文引号不能代替代码中的英文引号。第一节不需要自定义函数、JSON、接口或 F5。

## 保存、运行与报错自检

| 看到什么 | 先检查什么 | 修复后怎样验证 |
| --- | --- | --- |
| 还是输出旧文字 | `main.go` 是否已按 `Ctrl+S` 保存；终端是否在这份文件的目录 | 再运行 `go run .`，核对新句子 |
| `undefined: fmt` 或 `undefined: fmt.println` | 是否引入 `"fmt"`；`Println` 的 P 是否大写 | 恢复完整例子再运行 |
| `expected ...` 一类语法错误 | 报错行附近的英文引号、圆括号、花括号是否配对 | 修复语法后重新运行 |

不要只把“终端没报错”当作成功：本节的验收证据是**实际出现你刚写的新句子**。

## 合上示例，独立写两句输出

在已初始化的独立练习目录，从空白 main.go 自己组织包声明、导入、入口和两次打印。第一句是“学习计划开始”，第二句是“今天写两句程序”。**不能复制整份例子再替换文字；先写完整预期，再把结构和语句写出来。**

保存并运行，终端应恰好显示两行，顺序与上面一致；两句不能挤在同一行。再交换你写的两条打印语句位置，预测顺序并核对。最后说明程序从哪个函数进入、哪两次调用产生了两行文字。

### 参考答案

原顺序是“学习计划开始”后“今天写两句程序”，交换调用位置后顺序也交换。包声明和导入不产生这两句输出；入口内的两次 Println 才会按顺序打印。用自己的完整文件和终端结果自查，不只提交两句文字。
