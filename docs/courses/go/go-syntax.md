# 注释和基本语法

区分注释与执行语句，理解名字大小写和括号配对。

## 注释和基本语法是什么意思

注释是写给人看的说明，编译器不执行它。`//` 注释到该行结尾，`/* ... */` 可以跨多行。变量和函数的名字区分大小写。语句通常一行写一条，不需要在每行末尾手工加分号。

## 代码里的标点不能随意换

**注释是说明，字符串是数据，执行语句才会产生动作。** 例如 `// 第一行` 不显示文字，而 `fmt.Println("第一行")` 会显示文字。字符串内部的 `"//"` 仍是文字，不会让后面的内容变成注释。

| 符号或写法 | 本课中的作用 |
| --- | --- |
| `// ...` | 从两个斜杠到这一行末尾是注释 |
| `/* ... */` | 从开头到配对的结尾是块注释，可跨多行 |
| `main`、`fmt`、`Println` | 名字；大小写不同代表不同名字 |
| `("第一行")` | 圆括号装本次调用的参数 |
| `{ ... }` | 花括号划定 main 函数体的范围 |

空格与缩进让人读得清楚；Go 的格式化工具 `gofmt` 会统一缩进。先保证程序正确，再在 VS Code 保存时观察格式化，格式化不能替你补回缺失的逻辑。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	// 单行注释只说明下面的语句，这一行本身不会打印。
	fmt.Println("第一行") // 语句末尾也可以写注释。
	/* 块注释可以跨行。
	   这里的文字也不会执行。 */
	fmt.Println("第二行")
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
第一行
第二行
```

## 逐步读懂这个例子

两次 Println 依次执行，所以得到两行。注释里的汉字没有引号也不会被当成字符串。`{` 与 `}` 包住 main 内的语句；函数调用的 `(` 与 `)` 包住参数，两种括号用途不同。

这份程序从上往下遇到两种内容：注释直接跳过，打印语句依次执行。块注释结束的 `*/` 必须保留；不能在块注释里再嵌套另一组 `/* ... */`。

名字通常用字母开头，后面可跟字母、数字、下划线，例如 `score1`。`1score` 不能作为变量名，`func`、`package` 这类已被语言占用的关键字也不能拿来随便命名。变量的声明会在下一课实际练习。

## 自己改一处再运行

给第二个 Println 的开头加上 //，再运行；随后去掉它。

### 参考答案

加注释后只输出第一行，去掉后恢复两行。

## 本节容易混淆的地方

注释掉代码会改变行为。把 Println 改成 println 会变成不同名称，先核对报错中的文件和行号。

## 让错误帮助你认清语法

一次只故意改一处：先把 `Println` 改成 `println`，保存运行，找到错误里的名称，再恢复；然后删掉一个右圆括号，看报错指向哪一行，再恢复。**有语法错误时程序不会执行完整例子，不应期待原来的两行输出。**

能说明“哪一行是注释、哪一行会执行、哪两个括号配对”，才完成本节的辨认任务。

## 合上参考，自行安排说明与语句

从空白 main.go 写一份“今日安排”：终端只输出“先阅读”和“再练习”两行。自己选择位置写一个行注释和一个跨两行的块注释，注释中分别说明两项安排的原因，不把说明放进输出字符串。

先圈出应该显示的文字、写出两行预期，再保存运行。**注释文字不应出现在终端，两条执行语句应各产生一行。** 然后在自己的源码中暂时漏掉一条打印的右圆括号，记录编译错误对应的位置；自己恢复括号，确认两行输出回来。

### 参考答案

正常输出依次为“先阅读”“再练习”，注释内容没有输出。缺圆括号时不能得到这份正常结果，修复后才恢复。你的注释位置可以与参考不同，但需要能区分说明、字符串和执行语句。
