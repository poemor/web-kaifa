# 切片与 append

用切片保存可增长的一组整数，理解长度与切片范围。

## 切片与 append是什么意思

切片用[]int表示，它描述一段数组数据。与[3]int不同，[]int不在类型里写长度。append返回追加后的切片，需要接住这个返回值。a[起点:终点]包含起点、不包含终点。

## 切片的长度可以随追加改变

**切片描述一段元素数据；append 的返回值才代表追加后的新切片。** `[]int` 没有把长度写进类型，`[]int{60,80}` 当前长度是 2。`[3]int` 的数组长度则固定在类型里。

切片范围 `scores[1:3]` 包含下标 1、2，不包含 3，所以有 `3-1=2` 项。省略起点的 `scores[:2]` 从 0 开始；省略终点的 `scores[1:]` 取到当前长度末尾。仅有 `scores[1]` 时取得一个整数，不是一个切片。

空切片 `[]int{}` 当前没有元素。`var scores []int` 的零值叫 nil 切片，也没有元素，两者都能 append；但它们都没有可以读取的下标 0。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	scores := []int{60, 80} // []int 类型不写固定长度，当前有两项。
	// append 返回追加后的切片；赋值才能让 scores 代表新结果。
	scores = append(scores, 100)
	fmt.Println(scores, len(scores))
	// 范围包含下标 1、不包含下标 3，因此读到第二项与第三项。
	fmt.Println(scores[1:3])
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
[60 80 100] 3
[80 100]
```

## 逐步读懂这个例子

初始两项，append之后三项。scores[1:3]取下标1、2的值，所以是80、100。切片不是独立拷贝数据的承诺；下一节用修改实验看共享。

赋值执行前 scores 表示 `[60 80]`。`append(scores,100)` 计算追加结果，外面的 `scores =` 保存返回值；之后长度为 3，再取 `[1:3]` 才能看到 `[80 100]`。

切片还有容量，`cap(scores)` 表示从当前起点可使用的底层元素空间。长度以内的项才能直接索引，容量有余量也不意味着可以随意写 scores[len(scores)]。append 可能复用原空间，也可能分配新空间，具体共享由下一课实验确认。

## 自己改一处再运行

再追加90，取scores[0:2]并预测输出。

### 参考答案

完整切片是[60 80 100 90]，前两项是[60 80]。

## 本节容易混淆的地方

append不能靠忽略返回值来可靠更新变量。空切片与nil切片都可append；下标访问仍须在长度以内。

## 零项与范围实验

先将初始值改成 `[]int{}`，只保留 append 和完整切片输出，预期得到 `[100] 1`。原来的 `[1:3]` 范围不再合法，删掉或调整这个取片操作后再运行。

写成 `append(scores,100)` 而不使用返回值会被编译器拒绝。这能提醒你：**追加是一次产生新结果的调用，需要明确接住结果。**

## 合上参考，独立展示至多两项清单

从空白 main.go 管理一个字符串切片清单。先独立实现“展示当前完整清单、长度以及至多前两项”，展示范围由当前长度决定，不能一律取到下标2。

| 当前清单 | 长度 | 展示的前至多两项 |
| --- | --- | --- |
| 空清单 | 0 | [] |
| Go | 1 | [Go] |

再从两项清单追加“SQL”，自行接回追加结果。完整清单应为 `[Go Web SQL]`、长度3，而展示仍为 `[Go Web]`。**零项时也要执行你写的展示逻辑，证明它不会越界。** 可直接写在 main 中，不需要尚未学习的 range 或多返回值函数。

### 参考答案

先由长度决定实际终点，再取片；没有元素时终点为0。追加后的完整清单与用于展示的前两项是两个不同范围，接回 append 结果后才能正确看到第三项。
