# 字符串与终端输出

连接字符串，区分打印文字与打印变量。

## 文字、变量名与格式占位符

**字符串保存文字；变量名是代码里的名字，两者不能因为看起来相似就互换。** `name` 读取变量，`"name"` 是四个字母组成的文字。

| 写法 | 作用 |
| --- | --- |
| `"你好，" + name` | 连接两段字符串 |
| `fmt.Println("你好，", name)` | 打印两个值，中间有空格，末尾换行 |
| `fmt.Print("你好")` | 打印后不额外换行 |
| `fmt.Printf("%d 分钟\n", 20)` | 按格式插入整数，再换行 |

双引号字符串里，`\n` 是换行、`\t` 是制表符、`\"` 是一个文字双引号、`\\` 是一个反斜杠。反引号包住的字符串保留内容原样，例如 `` `a\nb` `` 包含反斜杠和字母 n，不会在这个位置换行；后面写 JSON 输入时会用到它。

## 字符串字面量与三种输出方式

双引号字符串解释转义，反引号字符串保留换行与反斜杠。两者产生的都是 string，选哪种取决于要保存的内容，而不是有两种文字类型。

```go
fmt.Printf("%q\n", "第一行\n第二行") // 输出带转义的可辨认形式。
fmt.Println(`C:\notes\go`) // 反引号内的反斜杠原样保留。
```

字符串是不可变的字节序列。`text = text + "!"` 是把连接结果重新赋给变量，不是修改原文字内部的一项。长度和中文字符计数在 [字节与 rune](go-unicode.md) 详细实验。

Print 只输出值，Println 在值之间加空格并在最后换行，Printf 按格式输出且不自动换行。要生成字符串供后续保存或比较，用 `fmt.Sprintf("今天 %d 分钟", minutes)`；Sprintf 返回文字而不打印。先在终端练清这四者，再把字符串用于文件或 HTTP。

## 先运行一个小例子

在已初始化的独立 Go 练习目录中，把下面完整代码保存为 main.go。本节替换原文件，不在文件末尾追加另一份 main 函数。

```go
package main

import "fmt"

func main() {
	name := "小林" // 引号包住文字；name 是保存这段文字的变量。
	// + 把两段字符串连接，最终输出不包含源码中的引号或加号。
	fmt.Println("你好，" + name)
	// %d 由后面的整数 20 替换；\n 让输出另起一行。
	fmt.Printf("今天练习 %d 分钟\n", 20)
}
```

在这个目录的终端运行：

```sh
go run .
```

预期输出：

```output
你好，小林
今天练习 20 分钟
```

## 逐步读懂这个例子

name 保存称呼。加号把固定文字与变量的内容连接起来。Printf 的 %d 是整数位置，后面的 20 填入这个位置，\n 表示换行。代码中的 +、引号和格式符不是最终输出的一部分。

第一行先读到 name 保存的“小林”，再把固定问候与它拼成“你好，小林”。第二行不是字符串加法：Printf 在 `%d` 的位置显示整数 20，并解释 `\n` 为换行。

格式中的 `%s` 可插入字符串，`%d` 可插入整数；占位符按后续参数的先后顺序对应。这里只输出文本，没有从终端读取输入。

## 自己改一处再运行

把 name 改为自己的称呼，把分钟数改成 30。

### 参考答案

称呼按题意可换成自己的名字。分钟数仍是整数，由 %d 格式化进句子。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	name := "阿青"
	fmt.Println("你好，" + name)
	fmt.Printf("今天练习 %d 分钟\n", 30)
}
```

预期结果：

```output
你好，阿青
今天练习 30 分钟
```

## 格式不匹配的现象

`fmt.Printf("%d", "30")` 不会把文字转换成整数，运行时会出现 `%!d(string=30)` 一类格式诊断。核对占位符和参数类型；需要文字用 %s，需要整数用 %d。漏写末尾的 `
` 则会让下一条输出紧接着出现。

## 做两组可区分的实验

先打印 `"name"` 与 name，预期分别看到 name 与小林。再把第一条输出的 `Println` 改成 `Print`，第二条保持原样，观察两句会连在同一行；恢复 Println 后重新核对。

直接写 `"练习" + 20` 会产生类型错误。要插入分钟数，使用已讲的 `Printf`，而不是给数字乱加引号后继续做加减。

## 合上参考，独立生成学习报告

从空白 main.go 保存称呼“阿青”和分钟数30，输出两行：“阿青的学习记录”和“今天练习 30 分钟”。由你选择字符串连接或格式化输出；称呼与分钟数必须从变量读取，不把完整结果整句硬写死。

先写预期，再保存运行。将称呼改为“学习小组”、分钟改为0，第二轮应为“学习小组的学习记录”和“今天练习 0 分钟”。**两轮都核对占位符或连接的对象，以及是否正好换成两行。**

### 参考答案

第一行连接两个字符串，第二行把整数按格式插入。再改 name = "学习小组"、minutes = 0，预期是“学习小组的学习记录”和“今天练习 0 分钟”，两次都必须从变量读取。

下面是可直接替换的完整 `main.go`。在本节独立模块中保存后运行 `go run .`。

```go
package main

import "fmt"

func main() {
	name := "阿青"
	minutes := 30
	fmt.Println(name + "的学习记录")
	fmt.Printf("今天练习 %d 分钟\n", minutes)
}
```

预期结果：

```output
阿青的学习记录
今天练习 30 分钟
```
