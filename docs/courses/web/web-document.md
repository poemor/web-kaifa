# HTML 文档结构

分清head与body，写出一张只包含标题和段落的网页。

## HTML 文档结构是什么意思

HTML使用标签描述内容结构。浏览器读取文件后把body里的内容显示出来；head保存标题、编码等页面信息。先用最小页面，逐项认识组成，不先做复杂社团首页。

## 一张文档的外壳与正文

**`head` 放页面信息，`body` 放要显示的内容。** 它们都位于最外层的 `html` 中。缩进帮助人看出层级；浏览器主要按标签的嵌套关系解释结构。

| 这一行 | 具体作用 |
| --- | --- |
| `<!doctype html>` | 文档类型声明，让浏览器使用现代 HTML 的标准模式；不是一段正文 |
| `<html lang="zh-CN">` | 文档根元素；`lang` 是属性，指出主要语言为简体中文 |
| `<meta charset="UTF-8">` | 指定文字编码；文件也应在 VS Code 右下角保存为 UTF-8，避免中文乱码 |
| `<meta name="viewport" ...>` | 指定移动端布局视口与设备宽度一致，初始缩放为 1 |
| `<title>...</title>` | 标签页和书签使用的文档标题 |
| `<h1>...</h1>`、`<p>...</p>` | 正文中的一级标题和段落 |

创建并保存的是 `index.html`，不是 Word 文档。打开后预期正文有“我的第一张网页”和“今天开始学习 HTML。”，标签页则是“本节小练习”。

## 先看一个完整例子

在自己的独立练习文件夹新建 index.html，保存下面完整内容，用浏览器打开。修改后先保存，再刷新。

```html
<!-- 文档类型声明：采用现代 HTML 的标准模式。 -->
<!doctype html>
<html lang="zh-CN">
<!-- 页面信息放在 head 中。 -->
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>本节小练习</title>
</head>
<!-- 显示给读者看的标题和段落放在 body 中。 -->
<body>
<h1>我的第一张网页</h1>
<p>今天开始学习 HTML。</p>
</body>
</html>
```

## 逐步读懂这个例子

doctype声明采用现代HTML规则。html包住文档，lang声明主要语言。charset使中文按UTF-8解释。viewport让手机按设备宽度显示。title是浏览器标签页文字，不是正文大标题。body里的h1是主标题，p是段落。

## 自己改一处再观察

分别修改title与h1，保存并刷新，观察两个位置。

### 参考答案

标签页随title变化，正文标题随h1变化，两者互不替代。

## 本节容易混淆的地方

HTML代码保存在index.html中。网站练习框不会自动改动你的本机文件；没保存就刷新会继续看到磁盘旧内容。

参考：[MDN Web 学习文档](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)。

## 独立变式：制作食谱说明页

**先合上原例，再从空白文件完成下面的目标。** 可以查本节概念和已经学过的章节，先写自己的预期；不要复制参考程序再换几个字。只使用本章的文档外壳、title、h1、p，不要求样式和交互。

新建 recipe/index.html。标签页叫“我的厨房笔记”，正文有一个菜名主标题与两段分别说明食材和步骤的文字；两段不能靠很多空格或换行拼出。先写出标签页和正文的预期，再独立组织 head/body。

自查：标签页显示“我的厨房笔记”，正文只有一个主标题和两个独立段落；修改标签页标题不能改变菜名。保存后刷新仍显示自己的内容，移动一段到 head 不会成为正确的正文结构，要恢复到 body。
