# 层叠、优先级与继承

判断同一属性最终使用哪一条规则。

## 层叠、优先级与继承是什么意思

多条规则可能匹配同一个元素。浏览器先考虑规则来源等条件，再比较选择器权重，权重相同时看后出现的规则。部分文字属性可从父元素继承，但并不是所有CSS属性都会继承。

## 用同一个属性追踪最终结果

**先看规则是否直接给当前元素赋值，再判断直接规则之间谁胜出。** 本例 div 是 p 的父元素，div 的绿色可以被后代继承；但 p 有直接声明时，不使用这份继承颜色。

在本例这种同一来源、未分层且没有 important 的普通规则中：ID 选择器的优先级高于类选择器，类高于标签；优先级相同才看谁写在后面。浏览器层叠还包括来源、重要性和层等条件，这个判断不是“任何时候看最后一行”。

按顺序预测并观察：三条都在时红色；删掉 `.note` 时蓝色；再删掉 `p` 时才继承绿色。`color`、文字字体等通常继承，`margin`、`border` 等通常不继承。

按 F12 打开开发者工具，选择 Elements（元素）面板，点选这个 p，再看 Styles（样式）中哪些 color 被划掉；Computed（计算值）显示最后颜色。工具只用于观察：在面板中改规则是临时修改，要保存仍得回编辑器改文件。

## 先看一个完整例子

在自己的独立练习文件夹新建 index.html，保存下面完整内容，用浏览器打开。修改后先保存，再刷新。

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>本节小练习</title>
  <style>
/* 父元素的颜色可供后代继承，但不会覆盖子元素直接指定的颜色。 */
div { color: green; }
/* 直接匹配段落，先于继承值参与选择。 */
p { color: blue; }
/* 同样直接匹配段落；本例中类选择器优先级高于标签。 */
.note { color: red; }
  </style>
</head>
<body>
<div><p class="note">观察我的颜色。</p></div>
</body>
</html>
```

## 逐步读懂这个例子

最终段落为红色。.note直接匹配段落，权重比标签p高；div提供的绿色只在子元素没有直接指定color时通过继承发挥作用。先判断是否直接指定，再比较规则。

## 自己改一处再观察

删除.note规则再观察；再删除p规则。

### 参考答案

先变蓝，再继承div的绿色。

## 本节容易混淆的地方

不能说“最后一条CSS永远生效”。!important不是解决所有覆盖问题的工具，先看匹配与权重。

参考：[MDN Web 学习文档](https://developer.mozilla.org/zh-CN/docs/Learn_web_development)。
