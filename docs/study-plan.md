## 两条路线如何衔接

先完成一小段学习闭环，例如一个 Web 页面或 Go 第一个 HTTP 接口，再切换方向。学过 Web 请求与 JSON 后，可以用 Go 接口提供数据；完成 Go CRUD 后，再让 Web 页面调用自己的后端。

全栈教材中的后端内容可以作为概念参考。使用 Go 实现时，以 Go 教材和自己项目的 API 契约为准，不必同时实现多套后端技术栈。

每天留存三样东西：自己写的代码、实际运行或测试的结果、当天仍不理解的问题。复盘模板见 [每日笔记](../templates/daily-note.md)。

## 需要补练时，从一个小任务开始

网站的“知识地图”按基础、应用、综合组织 24 个主题，“练习工坊”提供 18 个任务。这些是教材的补充，不把参考例子运行成功当作学习完成。已有编程基础者可以先做独立任务，遇到边界再回看概念；零基础者先按课时，再用起步提示完成最小步骤。

| 当前学习段 | 建议补练 | 要留下的结果 |
| --- | --- | --- |
| Web 第 1–7 课 | 语义介绍页、盒模型测量、Flex / Grid 布局 | 自己的代码、尺寸预测与实测、结构解释 |
| Web 第 8–14 课 | 长内容与手机布局、键盘表单 | 多视口截图、焦点与校验检查、没有伪造提交成功 |
| Web JavaScript 后续阶段 | 纯函数筛选、活动搜索、请求状态 | 正常与空输入、加载 / 成功 / 空 / 失败结果 |
| Go 第 1–7 课 | 分数统计、词频、结构体、HTTP 基础 | `go run` 输出、表驱动测试、非法输入响应 |
| Go 第 8–21 课 | JSON 边界、CRUD 契约、数据库约束 | 请求与响应、真实测试库结果、失败事务回滚 |
| Go 第 22–28 课 | 两用户隔离、取消与退出 | 拒绝跨用户操作、取消信号结果、复现说明 |

四套实际可运行的参考起点：[活动搜索](../exercises/web/activity-filter/README.md)、[请求状态](../exercises/web/request-states/README.md)、[词频统计](../exercises/go/wordfreq/README.md)、[HTTP 基础](../exercises/go/http-basics/README.md)。其他工坊任务写明需要已有项目或数据库的条件，不是已经实现的项目功能。
