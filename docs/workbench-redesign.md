## 审核范围与结果

这次由实现对话进行代码差异审查、自动化回归与实际截图检查，不宣称外部独立审计，也不保证覆盖全部未来使用情况。

1. 数据兼容：保留现有存储字段和版本，导入、导出、撤销和异常原记录保护未改动。
2. 预览隔离：保留 `sandbox="allow-scripts"`，不加入 allow-same-origin；保存的修改草稿不自动执行。编辑时收起旧结果，再次运行才显示新结果。
3. 完成规则：验收勾选与正确小测仍是记录完成的前提；阅读、提问、复制不改变完成状态。
4. 上下文边界：侧栏按课隔离问题、代码选择和提问快照；普通页面进入自由提问，不带入上一课代码。
5. 内容处理：动态课程、代码与问题以转义 HTML 或 textContent 呈现；现有 Markdown 安全处理保留。
6. 无障碍：三个课内标签支持方向键、Home/End；移动端窗口隔离背景并约束焦点；模型对话框先关闭，不会同时关闭侧栏。
7. 审核修正：从侧栏内部操作后关闭窗口时，焦点归还顶部入口，避免落入已隐藏元素；Go 恢复片段后显示“本机运行”，不声称网页已经执行；撤销完成条件时同步课程目录标记和页头状态。
