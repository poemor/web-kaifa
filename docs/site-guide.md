# 开发练习册怎么用

## 按层级学习系统教程

“Web开发”和“Go后端”按入门、初阶、中级、高级组织125个章节。选择方向后，左栏显示该方向的章节目录，每页最多8章；阶段选择和翻页只更新目录，保持正在读的正文、滚动位置和助教草稿。地址保存目录阶段与页码，刷新和浏览器返回可以恢复。手机点击顶部“目录”，选章后收起。

正文一次展示一章：先解释概念，再给注释代码、逐步说明和修改实验。本节小目录放在左栏，正文保留可展开的前置章节与上一节、下一节入口；深链接自动定位左栏中对应阶段和页码。阶段项目和原课时的笔记、代码草稿在左栏另设入口。完整大纲见 [教学大纲](teaching-outline.md)。

每层包含阶段实战。新增学习时长计算器、学习名片页和响应式活动页有独立源码ZIP；后续复用真实词频、搜索、CRUD、数据库、会话和恢复项目。按每个README准备环境，数据库/容器不能在静态网页里运行。阅读、复制、下载不自动完成学习。

原42节课保留原笔记、代码草稿与验收。每课先显示对应的具体基础讲解，工程参考默认收起；12个后续阶段也列出先学章节。新章节不会沿用含义不同的旧完成标记。Go第1课的默认源码只有打印一句话，自己的已保存草稿优先保留；切换参考可使用原有可撤销恢复操作。

## 先准备工具，再开始第一课

首页和导航中的“安装与起步教程”包括四个部分：安装 VS Code、Web 环境、Go 环境、学会问 AI。各节写明文件放在哪里、命令在哪里输入、预期输出与常见错误；Web 和 Go 第 1 课也提供环境检查入口。已有环境可以直接按运行结果自查。

先安装编辑器，再选 Web 或 Go 中的一条；不需要同时配置两条路线。左侧目录可跳到当前步骤，手机通过顶部“目录”展开；代码框可复制完整内容，这些操作不会执行代码。提问整理器生成结果后会定位到结果，可复制到自己使用的 AI 工具；刷新前自行保存草稿。Web 的保存/刷新练习与 Go 的大小写排错练习用于观察实际错误和练习反馈，不会自动计入课程完成状态。

Go 环境页先按“还没下载 / 已下载 / 找不到命令 / 能运行”选择起点：下载页实拍解释系统、架构与文件后缀，Windows MSI、macOS PKG 和 Linux 归档分别说明；PATH 排查区区分 cmd 与 PowerShell，并说明 GOROOT、GOPATH、GOMOD。章节目录统一放在最左栏，手机展开“目录”后可选步骤；选择后收起并定位正文。安装包选择、各系统安装与 PATH 都有带 step 的直达链接，可刷新与分享；搜索 PATH、amd64 或 arm64 也能定位对应章节。

起步页负责文件、终端、工具安装与运行验证；Go变量、输入和文件改由系统教程按前置顺序讲解。代码框标明内容放文件还是终端，预期输出只供对照。Go环境第6节保留编译与重新构建实验，第7节说明初阶输入与项目的入口。

VS Code 第8–13节继续教插件与工具安装、工作区层级、settings/tasks/launch/extensions 四个 JSON、任务菜单、编译快捷键、F5 断点与输入程序的调试位置。四张真实界面图可点击放大，完整 Go 起步包包含配置和源码。Windows cmd 用 `hello.exe` 或 `.\hello.exe`，PowerShell 用 `.\hello.exe`；Unix 用 `./hello`。先核对终端，不把 `./hello.exe` 当作通用 Windows 写法。

Go第1课的运行准备默认收起，正文先教程序结构；需要时查看初始化命令与缺模块修复，F5在学过变量后选读。复制不执行、不更新验收，带step的修复链接可刷新和分享。

课内“先学本课用到的基础”显示对应系统章节，补充前置给直接入口；“项目参考与扩展讲义”才包含知识地图专题。参考答案默认折叠，先尝试再查看；阅读与复制不写学习完成状态。原知识专题作为需要时的完整参考继续保留。

“学会问 AI”包含模糊问题与可排查问题的对照、六项证据骨架、收到回答后的验证方法，以及问题整理器。填写目标和实际结果后可生成文字，缺少的信息明确标为待补充；修改后旧结果收起，刷新前请自行复制。它只保存当前页面会话草稿，不调用模型、不写入课时进度。顶部搜索也能找到这些教程。

## 先选自己的起点

首页先选 Web / Go，再选“第一次写代码”或“写过代码”。当前课优先使用所选方向的上次未完成课程；切换方向不会清除另一条路线的学习记录。零基础从第一课创建文件、运行程序开始；Go 的 C++ 对照可以先跳过，第 2 课另有不需要原语言基础的练习。

有编程基础的人可以先看动手任务，能独立通过验收再跳过讲解。不要因为看懂语法就略过浏览器布局、输入校验、数据持久化或权限检查。

## 用知识地图与练习工坊补薄弱点

左侧“知识地图”提供 24 个主题，可按 Web / Go、基础 / 应用 / 综合以及关键词筛选。每个主题有解释、例子、常见误区、前置知识和对应练习。先预测输出，再展开参考解释，最后换一个输入验证。

“练习工坊”提供 18 个任务，每个都写明目标、启动方法、起步提示、独立任务、输入输出验收与加练要求。四套配套文件可实际运行；其他任务明确需要自己的已有项目或数据库。配套起点已实现与待练习的功能在说明中分开标注。

筛选条件写入地址栏，刷新与浏览器返回可以恢复。顶部搜索同时查课程、知识与练习。进入课程时，“读懂任务”标签也会显示补充概念和相关练习；Web JavaScript 后续阶段有专项入口。

练习的“复制验收与复盘清单”生成带待填写结果的 Markdown，可以贴到自己的笔记。它不声称已经验收，也不自动改变课时进度。练习页的“运行起点演示”只在点击后执行原始片段，保持 iframe 隔离；它不能运行 Go 或请求站外 API。需要修改代码时保存到自己的练习目录，或使用现有课内编辑区。

知识与练习内容及参考依据见 [优化记录](learning-content-upgrade.md)。

## AI 助教与开发方法

进入任意课程，点击“带着本课提问”，或使用顶部“AI 助教”。助教默认收起；打开后保留本次页面会话内的手动选择。1200px 及以上与正文并列，1199px 及以下在正文后、页脚前上下排列。小屏打开时定位助教标题，可用“收起并回到刚才的位置”、关闭按钮或 Escape 返回原触发位置。任务、代码与验收之间切换不需要离开课程。

侧栏默认只带入本课任务和验收标准；勾选“我编辑的代码”后才加入代码。点击“查看本次提问的上下文”可以检查内容，整理后复制到自己的 AI 工具。更改问题、代码或上下文后，旧提问文字会收起，需重新整理后再复制。多行问题用 Enter 换行；Ctrl+Enter 整理（Mac 为 Cmd+Enter），也可以点击“整理提问”。

“怎样用 AI 开发”页面讲解描述需求、拆任务、证据排错与验证复盘。需要更详细的报错、尝试和提示深度设置时，进入“提问模板与工具”。

选择“一个线索”“下一步检查”或“最小示例”，复制生成的文字到自己使用的 AI 工具。先改一处并重试，再换一个输入检查，最后收起回答，用自己的话解释和复写关键部分。

提问台不调用模型，也不把内容发送到服务器。切换课程会切换该课的提问草稿，避免混用 Web 与 Go 的代码；这些提问草稿只保留在当前页面会话。课内笔记和课内代码则随浏览器进度保存。

未连接扩展时，侧栏与完整提问台分别保留自己的页面内草稿；服务选择只是标记准备使用的工具。连接官网桥接扩展后，右侧使用扩展自己的聊天历史与草稿，真实回复由官网标签页同步，使用你自己的登录账号；对应官网页需保持打开，可留在后台。

## 阅读与实际操作

Web 后续12阶段按共同基础、前端、全栈衔接，每页默认显示完整补充讲义：原理、完整文件、操作步骤、预期结果、排错、独立练习与参考解答。原教材阶段清单保留作对照。左侧显示全部阶段，章节按钮可定位长文；源码 ZIP、README 与正文使用同一份参考代码。下载后全部解压，再打开包内独立项目，按 README 执行；不要在 ZIP 中编辑或在学习资料根目录初始化 Go 模块。

第00阶段补 SVG 绘制、PNG 导出、透明背景、图片路径、尺寸与裁切；后续包含 JavaScript 状态、TypeScript 校验、React 与 Vue 等价示例、实际测试、Go 接口、PostgreSQL 约束/事务、用户权限与备份恢复。服务器与数据库在电脑上运行。阶段阅读、源码下载、复制及带上下文提问都不会修改42节课的完成状态；成果与复盘自行保存在仓库。

课内分为“读懂任务”“动手写”“验收记录”三个标签。默认先显示任务，完整讲义和提示可以展开。课内侧栏优先显示当前课程目录，其他入口在“全部学习内容”中；手机通过顶部导航按钮展开目录。标签可用键盘左右方向键切换；切换保留本课草稿，并将新内容开头定位到标签下，读长讲义后也能看到验收题目。

Web 的代码编辑区是真实 HTML / CSS / JavaScript 预览，运行于隔离页面；外部请求和页面导航受到限制。修改草稿后旧预览会收起，点击“运行预览”才执行新代码。课程需要完整项目、接口或服务器时，按讲义在本机操作。

Go / SQL 的片段不能在静态网站内执行。注意片段依赖、所在目录和文件；把运行命令与真实结果记下来。原先编辑或导入的 Web 草稿不会在刷新后自动执行，检查后手动点击运行。教程更新不会覆盖自己的已保存草稿；需要新版起点时点击“恢复课程示例”，可以撤销。Web 第12课的新版起点仅检查本地输入，不发送或保存表单字段。

## 如何记录完成

在“验收记录”中，每课有验收勾选和一道理解小测。完成验收、答对小测后，点击“记录本课完成”。这表示你主动确认做过本课练习，不是资格认证，也不会因为 AI 说对了就自动完成。

把自己的解释、错误与运行结果写进课内笔记。取消验收勾选或改成错误答案，会撤销这节课的完成状态，方便回来补练。

## 换电脑与备份

在“我的进度”导出完整 JSON，包含课时、验收、小测、笔记和代码草稿。新浏览器导入后继续学习，导入会替换当前记录，可以立即撤销。导出 Markdown 方便保存到仓库，但完整代码草稿要保留 JSON。

原 Web 手册导出的 Markdown 和原 Go 手册导出的 JSON 与新网站的格式不同，不会自动合并；请保留原备份，对照自己的实际结果更新新网站。

文件模式、`localhost` 与在线网址的浏览器存储各自独立。清理浏览器数据也会清除记录，重要成果应定期导出。浏览器无法保存或读取异常记录时，网页会显示提示；能读取到的异常原文会单独保留供下载。

## 网站维护

网站是静态 HTML / CSS / JS，入口位于仓库根目录。GitHub Pages 从 `main` 的根目录发布，`.nojekyll` 让教材和网页资源按原文件提供。

统一阅读布局在 `assets/reader-layout.js` 和 `assets/reader-layout.css`：将已有目录放到同一左栏，保留原事件与正文，代码和表格局部横滚。修改后运行 `node scripts/test_reader_layout.cjs`，覆盖8种宽度、正文保持、目录定位、键盘滚动、课内重建与旧状态；再执行原有状态与交互检查。发布后的 `node scripts/verify_deployment.cjs` 核对线上入口、脚本样式、125篇正文与路由、19页目录及全部源码ZIP的实际内容，不把本机验证当作线上验证。

课程数据在 `assets/data/curriculum.js`，零基础补充和预览底板在 `adaptations.js`，知识、练习与阶段验收在 `learning-lab.js`；AI 模板和资料列表各有单独文件。新增展示在 `assets/learning.js` 与 `assets/learning.css`。原教材保持原样，修改补充内容时更新审核说明。详细知识讲义与课时专用包教程由 `scripts/build_knowledge_guides.cjs` 生成到同一离线数据包；第1、6课和表单第12课的展示采用补充版，原文仍可从资料索引对照。

运行 `node scripts/check_site.cjs` 检查课程覆盖和入口资源；运行 `python scripts/check_materials.py` 核对教材。浏览器交互检查需要 Playwright，可在依赖已安装的开发环境运行 `node scripts/test_site.cjs`，默认使用本机 Edge 和 `http://127.0.0.1:8743/`。其他浏览器通过 `PLAYWRIGHT_CHANNEL` 调整。

后续讲义源在 `docs/followups`；修改配套或正文后依次运行 `python scripts/build_followup_examples.py`、`node scripts/build_knowledge_guides.cjs`、`node scripts/version_site_assets.cjs`。`test_followup.cjs` 覆盖12阶段×7宽度、章节焦点、复制、下载哈希、分支导航、阶段提问上下文、搜索、离线和进度不变。Go 起步包由 `build_vscode_starter.py` 生成，`check_site.cjs` 同时检查源码下载和截图资源。本轮逐项审核见 [完整审核](followup-completion-review.md)。

工作台新增交互运行 `node scripts/test_workbench.cjs`，覆盖课程标签、侧栏上下文隔离、模型选择状态、键盘与窄屏窗口。`assets/workbench.js` 管理展示交互，`assets/app.js` 保持学习记录与验收逻辑；视觉变量统一在 `tokens.css`，工作台样式在 `assets/workbench.css`。设计规则见 [DESIGN.md](../DESIGN.md)，本轮审核见 [前端设计审核](frontend-design-review-2026-10-13.md)，历史记录见 [工作台改版说明](workbench-redesign.md)。

知识与练习新增交互运行 `node scripts/test_learning.cjs`。它检查新增内容路由、筛选与返回、复制清单不改变进度、手动隔离预览、移动布局与配套 Web 请求的正常和失败场景。Go 例子在各自模块目录执行 `go test ./...` 和 `go vet ./...`。


## 统一 AI 助教

日常只打开根目录学习网站。安装 0.2.1 或更新版本的官网桥接扩展后，网站右侧直接加载扩展的聊天面板，使用原扩展聊天存档。没有收到扩展回应时保留本地提问，可点“连接扩展”→“连接已安装扩展”检查，不据此断言尚未安装。正式课程、知识主题、练习详情共用上下文；相关代码需主动勾选，换页后取消勾选。聊天不会完成课程，预览仍需手动运行。

本机开发固定使用一个入口，例如 http://127.0.0.1:8743/；localhost、127.0.0.1 与不同端口各有独立的学习记录，需通过原网站的导出与可撤销导入迁移。扩展聊天仍在扩展自己的存档中。设计参考页继续作为参考文档，产品入口为正式网站。

0.2.2 的助教顶部只保留 AI 选择与一行状态，详细连接设置默认折叠；连接中或失败时才展开状态卡。输入框旁可勾选本课任务、代码和学习指导词，并使用“预览提示词”查看本次完整消息。指导词可编辑和按平台保存，是附带在用户消息中的文字。每 10 秒自动检查官网连接，也可手动“检查连接”，恢复不会重发问题。网站提示已加载旧版时，需要浏览器载入新版扩展一次；网页部署不能替换浏览器内的旧代码。

本轮零基础走查回归：`node scripts/test_walkthrough.cjs` 验证键盘跳到正文、课程示例恢复与撤销、Go 包路径以及复制到独立网页后的本地表单检查。Python 安装和静态服务器完整步骤在 Web 起步教程第6节；PostgreSQL 环境在 SQL 详细主题内。
