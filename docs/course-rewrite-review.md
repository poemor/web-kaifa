## 内容、项目与阅读

每章先解释当前概念，再提供注释代码、执行顺序、运行位置、正常与失败结果，以及独立组织的新任务。Go 从小程序和语法进入数据结构、HTTP、SQL、并发与可靠交付；Web 从 HTML/CSS 和 JavaScript 进入 DOM、请求、组件和完整前后端。框架之前讲它解决的具体问题，Go 既有 JSON API，也有 HTML 模板页面。

左栏选择 Go/Web、阶段与章节，每页最多 8 章；中间一次读一章。本节目录、前置、上一节与下一节帮助连续学习，目录翻页保留正文位置、答案和提问。原 42 课和 12 个项目阶段继续保留笔记、草稿与验收记录。

新增学习时长计算器、学习名片、响应式活动页和 Go HTML 模板独立工程及 ZIP；后续复用词频、请求状态、内存 CRUD、数据库 API、安全会话、组件与交付工程。完整 README、源码与示例同步，具体工具和环境按项目要求准备。
