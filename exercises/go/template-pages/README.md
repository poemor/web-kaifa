# Go 生成 HTML 页面

Go 1.22 或更新版本，无第三方依赖。`main.go` 接收请求，`page.html` 保存模板，`main_test.go` 验证 HTTP 响应和 HTML 转义。

在此目录运行：

```sh
go test ./...
go run .
```

打开 <http://127.0.0.1:8080/>，会看到“学习记录”和“今天学习 30 分钟”。再打开 <http://127.0.0.1:8080/?title=Go>，主标题和标签页标题变为 Go。按 Ctrl+C 停止；端口被占用时先停止自己的旧服务或修改 `main.go` 中的监听地址。

用下面地址验证转义，网页应把 `<script>` 显示为文字，不能弹出窗口：

<http://127.0.0.1:8080/?title=%3Cscript%3Ealert(1)%3C%2Fscript%3E>

查看 Network 中 HTML 响应，数据已经填入其中。关闭浏览器 JavaScript 后刷新，标题和学习分钟仍然显示。访问 `/missing` 返回 404。

修改 `page.html` 后重启 Go 服务，因为模板在启动时解析一次。把主标题位置错误地改成 `{{.Minutes}}`，`go test ./...` 应失败，修复后再通过。

限制：只读演示，分钟固定为 30，没有数据库、登录、记录保存、表单提交和线上部署配置；只监听本机。不要把用户输入转换为 `template.HTML` 来绕过转义。
