# 学习时长计算器

Go入门阶段的小项目，只用变量、乘法、函数、输出与条件判断。它用源码里的两个数计算计划时长，不记录实际学习完成情况。

在VS Code直接打开这个独立目录，终端运行：

```sh
go run .
```

默认输出：

```text
3 天共练习 60 分钟
已达到本次一小时目标
```

先把minutes改成15，days保持3，预测并验证45分钟与继续练习的提示；再试days为0。完成函数章节后从空文件独立重写，测试章节后运行 `go test ./...`。

这里没有用户输入、日期计算、数据保存或网站联动。负数不是本项目有效输入；初阶可加错误返回与输入校验。main_test.go给出正常值和零值的验证，不能把运行参考代码当成自己的课程完成。
