# 响应式社团页面

零依赖静态练习，四张卡片、两种比例本地 SVG、公告侧栏、键盘焦点、本地字段检查。

双击 index.html 可运行。使用 VS Code 打开本目录，修改后 Ctrl+S / Cmd+S，浏览器刷新。HTTP 预览：Windows `py -m http.server 8760 --bind 127.0.0.1`；macOS/Linux `python3 -m http.server 8760 --bind 127.0.0.1`；浏览器打开 http://127.0.0.1:8760/ 。终端 Ctrl+C 停止。

验证：360 / 768 / 1440px 没有横向溢出；四卡随屏幕自动排成 1 / 1 / 3 列（公告与列表在 768px 起并排）；长标题自然换行；横竖图不拉伸；Tab 焦点可见；点击两项 label 聚焦对应字段；空输入/全空格不能通过；合法条件只给本地检查提示，地址栏不增加表单内容。

知识解释、完整跟做、故障实作与参考答案见 [阶段讲义](../../../docs/followups/web-00.md)。

边界：无后台、账号、真实搜索/报名；示例邮箱不可投递；SVG 为本仓库绘制的教学图。固定回顶部按钮会占用一小块视口，真实产品要检查放大后的遮挡。

素材实作：打开assets.html，比较两份自绘插画；外部SVG与内联currentColor图标可运行；HTTP访问时直接导出实际calendar.svg；双击file:访问时先选择自己编辑并保存的calendar.svg，再点导出下载96×96透明PNG。每次编辑后重新选文件，PNG应保留日期点与新配色，显示48×48作2倍像素素材。PNG是运行时导出，不随源码提交。复制原图与改进图，自己调整配色/圆角/间距，再在主页面替换封面。
